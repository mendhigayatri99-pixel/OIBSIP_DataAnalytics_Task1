# OIBSIP_DataAnalytics_Task1
Exploratory Data Analysis on Retail Sales dataset using Python for Oasis Infobyte Internship Task 1.

Project Title:
Exploratory Data Analysis on Retail Sales Dataset

Objective:
To analyze retail sales data and identify patterns, trends, and business insights.

Tools Used:
Python, Pandas, Matplotlib, Seaborn, Google Colab

Steps Performed:
• Data cleaning
• Descriptive statistics
• Time series analysis
• Customer & product analysis
• Data visualization
